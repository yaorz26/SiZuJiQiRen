# 2026-10-24 离线分析：静止位姿、偏航与地图一致性

> 本文是离线分析记录，不是计划；当前行动依据见 [PLAN.md](PLAN.md)。所有结论均标注了证据边界，未把机载传感器一致性检查写成外部真值。

## 结论摘要

1. **机器人实际基本没有转动。** 对 10/10 充电后 A/B 两组十分钟静止包，用 `cloud_base` 做前后 60 s 的多起点 2D ICP：A 组相对转动 **+0.086°**、平移 **22.6 mm**，B 组 **+0.060°**、平移 **6.1 mm**；内点率 95.4% / 98.9%。场景静止、点云内点率高，结果在 A/B 两组一致。
2. **原厂里程计偏航在同一窗口内单调漂移。** A 组 **−3.456°**（−0.321°/min），B 组 **−3.762°**（−0.359°/min），而平面位置只变化 8.1 / 7.5 mm。即偏航漂移不是由平移或明显机身运动造成。
3. **实时 B 的“0.102 m / 4.30°”不是物理运动，也不是独立定位误差。** 分解为：
   - `map → odom` 平移变化 **0.1044 m**（占主导）；
   - `odom → base_link` 平移变化 **0.0090 m**；
   - `map → odom` 偏航变化约 **0**；4.30° 完全来自原厂里程计偏航，直接进入地图位姿。
4. **基线配置下 SLAM 完全跟随里程计偏航。** 十分钟 B 包回放中，`map→odom` 偏航全程为 0（数值上约 1e−14°），`map→odom` 平移从 0 增至 **0.090 m**；地图位姿偏航 = 里程计偏航 = **−3.778°**。因此问题是“偏航未被扫描匹配纠正”，不是机器人真的转了 4°。
5. **放宽角度先验的候选配置有效但未完全解决。** 将 `angle_variance_penalty` 从 0.005 调到 0.1、`minimum_angle_penalty` 从 0.1 调到 0.3 后：
   - `map→odom` 偏航修正到 **+2.40°**，地图位姿残余偏航从 −3.78° 降到 **−1.386°**；
   - `map→odom` 平移从 **0.090 m** 降到 **0.0587 m**；
   - 已观测面积基本不变（7.29→7.27 m²），自由连通碎片从 189 降到 169。
   - 但残余 1.386° 仍大于计划的 1° 目标，不能称为“已通过”。
6. **转向回归未出现失配，但也不能证明候选更准。** 新转向包：候选 SLAM 转角 −38.110°，里程计 −38.657°，基线 −38.704°；旧 72° 稀疏转向包：候选 71.073°，里程计 72.291°，基线 72.284°。候选相对里程计分别差 0.55°/1.22°，地图规模与图节点数基本不变，没有出现跳变或崩溃。由于没有独立转角真值，不能仅凭“更接近/更远离里程计”判断哪个更准。
7. **陀螺原始积分不能当作十分钟静止的角度基准。** A/B 两组原始积分分别为 **+106.66°/+21.54°**；用前 30 s 中位数去偏后仍有 **+31.27°/−15.09°**。零偏随时间和温度变化，短时 61 s 包也不能外推到十分钟。因此本分析以雷达 ICP 为主，陀螺只作旁证。
8. **地图存在厘米级不一致，但不是完全重影。** 以 B 实时地图中途基线（146×144）与结束快照（153×148）比较：旧占据格到结束图的最近邻中位 **1.5 cm**、90% 分位 **7.5 cm**、95% 分位 **11.5 cm**；结束图新增占据格到旧图最近邻中位 4.5 cm、90% 分位 18.0 cm。结束图占据格约为基线 2.7 倍，包含大量新增观测，反向统计更代表旧结构的保持程度。

## 解释与边界

- **雷达 ICP 是机载传感器一致性检查，不是外部真值。** 它假设 10 分钟前后场景静止；场景中人员移动、遮挡变化会影响结果。A/B 两组、多起点、高内点率支持“机器人基本未动”的结论，但不能替代地面标记、全站仪或相机测量。
- **里程计与陀螺都来自机器人内部，存在零偏/温漂。** 本次里程计偏航在 A/B 两组均为负向、量级相近，但陀螺原始积分差异极大；不能把任一内部信号单独当作静止基准。
- **地图框架平移不等于机器人平移。** `map→odom` 是 SLAM 对地图坐标系的修正量；机器人实际平移应由 `odom→base_link`、雷达 ICP 或外部标记判断。
- **候选配置的转向差异没有独立真值判定。** 基线“贴近里程计”来自强先验，不等于几何正确；候选偏离里程计也不等于错误，可能是扫描匹配在纠正里程计偏航。需要闭环/标记路线或独立转角测量才能下结论。
- **回放与实时不完全相同。** 实时 B 为 72 节点、回放为 63 节点；时序、DDS 和地图更新节奏不同。结论以回放的完整轨迹为主，实时快照作旁证。

## 对计划与明天现场的影响

1. **G2b 拆成两层：**
   - **物理静止**：10 分钟雷达 ICP 相对转动 <0.5°、平移 <5 cm；本次 A/B 为 0.06–0.09°、0.6–2.3 cm，通过。
   - **服务器估计/地图修正稳定**：地图位姿偏航变化 <1°、`map→odom` 平移 <5 cm；基线为 3.78°/9 cm 未通过，候选为 1.39°/5.9 cm 仍待验证。
2. **不要把 0.102 m / 4.30° 写成机器人运动或独立定位误差。** 记录中应写清分解：主要来自 `map→odom` 平移修正和里程计偏航。
3. **明天现场增加物理基准。** 在地面贴标记/画线，记录起始与结束照片，最好用相机固定视角；离线用 `analyze_stationary_icp.py` 复核机器人是否真的静止。原始陀螺积分不作为基准。
4. **候选配置已写入默认配置**（`angle_variance_penalty: 0.1`、`minimum_angle_penalty: 0.3`），并在配置文件注释中说明依据。明天现场冻结此版本；若转向/闭环出现异常，回退基线值（git 历史 `373e866` 中为 0.005/0.1）。
5. **下一次离线优先做：** 用独立转角/闭环标记判断候选与基线的转向差异；继续调整角度先验或加入静止检测；不要只用里程计比较。
