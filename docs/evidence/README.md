# 随仓库保存的小型实验证据

这里保存 2026-11-17 从 Elements 盘选取的 74 个小文件，共 369,936 字节。
范围包括 10/24 和 10/25 的分析 JSON、10/25 录制元数据与完整性摘要、
连续性报告、回放参数和质量报告，以及小型地图预览。
原始录制、完整轨迹、位姿图和密集点云仍在外盘。

`elements/` 下的相对目录结构与 `/media/yaorz/Elements/unitree_go2/` 一致。
文件按原字节复制，未改写其中的绝对路径、历史状态、时间或参数。
阅读归档报告时，其中的绝对路径代表原始外盘位置，不代表文件也被上传。

[复制清单](manifest_2026-11-17.json)逐一记录外盘相对路径、仓库路径、文件大小与 SHA-256。
全部外盘文件的校验值见[完整盘点清单](../data_inventory_2026-11-17.csv)。

`elements/analysis/2026-10-25/icp_A_raw/analyze_stationary_icp.py` 是当次分析脚本快照：
它读取 `/utlidar/cloud`，与主线脚本读取 `/utlidar/cloud_base` 不同。
保留该文件是为了说明原始点云对照实验的实际实现；它不作为新的默认入口。
其他源码快照的位置与哈希仍可通过外盘清单和各次回放元数据查找。

原始报告中的通过项只适用于各自指标。例如保存/重载通过不能推出独立几何、
十分钟稳定性或导航通过；短于十分钟的观察不能替代十分钟连续性验收。
10/25 的质量报告虽然保留了通用待办文字，具体连续性判定以其
`source_continuity` 和对应观察窗口为准。
